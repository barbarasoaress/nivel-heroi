# 🦸 Classificador de Nível de Herói

Desafio de lógica desenvolvido em **JavaScript** para classificar um herói de acordo com sua quantidade de experiência (XP).

## 🚀 Tecnologia utilizada

- JavaScript

## 🧠 Conceitos praticados

- Variáveis
- Estruturas condicionais
- Operadores relacionais e lógicos
- Classificação por faixas de valores
- Saída de dados com `console.log()`

## ▶️ Como executar

Com o Node.js instalado, execute:

```bash
node index.js
```

## 📚 Objetivo do projeto

Projeto desenvolvido como exercício de lógica de programação, aplicando estruturas de decisão para transformar uma quantidade de XP em uma classificação de nível.
